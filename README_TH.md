# Vexa Viral Thailand — Smart Product Manager V2

แอป Admin ภาษาไทยสำหรับจัดการสินค้า Shopee Affiliate โดยไม่ใช้ Shopee Open API และสั่งงาน GitHub Actions ผลิต MP4 ภาษาไทยวันละหนึ่งคลิปเมื่อมีงบเพียงพอ

## เปิด Admin ส่วนตัว
1. ที่ https://github.com/suntornsaeyo-glitch/dream-home-vexa-reels คลิก Code > Codespaces > Create codespace on main (หรือ default branch ของ repository)
2. รอ dev container ติดตั้ง requirements-admin.txt; หากยังไม่ติดตั้งให้ใช้ pip install -r requirements-admin.txt
3. ใน Terminal พิมพ์ bash admin/start.sh
4. เปิดแท็บ PORTS แล้วเปิดพอร์ต 8501 ในเบราว์เซอร์ ตรวจว่า Visibility เป็น Private เท่านั้น
5. Admin ใช้ GITHUB_TOKEN ที่ Codespaces จัดให้ฝั่งเซิร์ฟเวอร์ ไม่ต้องกรอก token ในหน้าเว็บ หาก GitHub ตอบ 403 ให้ตรวจสิทธิ์ Codespaces/Actions และใช้หน้า Actions โดยตรงเป็นทางเลือก
6. เมื่อไม่ใช้งาน ให้ Stop codespace เพื่อประหยัดโควตา GitHub Codespaces; GitHub Actions ผลิตคลิปได้ต่อโดยไม่ต้องเปิด Admin หรือคอมพิวเตอร์

Repository เป็นสาธารณะ: หน้า Admin เปิดแบบ Private แต่ไฟล์สินค้า ลิงก์ และต้นทุนประมาณการที่ commit ลง repository สามารถอ่านได้จากสาธารณะ ควรพิจารณาเปลี่ยน repository เป็น Private ก่อนใส่ข้อมูลจริง (ตรวจค่าใช้จ่าย Actions/Codespaces) ห้ามใส่รหัสผ่าน token หรือข้อมูลลูกค้าใน catalog

## เมนู
- ภาพรวม: จำนวนสินค้า จำนวนพร้อมโปรโมต จำนวนคลิปเดือนนี้ ประมาณการงบ ประวัติคลิป จัดอันดับคอมมิชชันต่อคำสั่งซื้อ และคำนวณกำไรจากตัวเลขรายงานที่กรอกเอง (ไม่บันทึกรายได้)
- รายการสินค้า: เพิ่ม แก้ไข ลบ เปิด/ปิดโปรโมต ยืนยันสิทธิ์ และบันทึก GitHub; ดาวน์โหลด JSON สำรองได้
- นำเข้า: ดาวน์โหลดแม่แบบ CSV/XLSX แล้วกรอกชื่อสินค้า ลิงก์ ราคา ค่าคอมมิชชัน (%) หมวดหมู่ คำอธิบาย; ค่าคอมมิชชัน 10% ให้กรอกเลข 10 ไม่ใช่ 0.10; นำเข้าเป็นฉบับร่างทั้งหมด ป้องกันลิงก์ซ้ำ ต้องตรวจและอนุมัติเองก่อนบันทึก
- งบประมาณ: แก้ data/settings.json ผ่าน Admin โดยมีเพดานวันและเดือน; ค่า variables เดิมอาจเป็นข้อจำกัดเพิ่มเติม กำหนดงบต้องยืนยัน
- ผลิตคลิป MP4: ทดสอบฟรีหรือสั่งสร้างจริงโดยยืนยันค่าใช้จ่าย ดูประวัติ Actions และดาวน์โหลด MP4 จาก Artifacts ผ่านลิงก์ของงาน (7 วัน)

## การหมุนเวียน
ใช้เฉพาะสินค้าที่เจ้าของยืนยันสิทธิ์และเปิดโปรโมต พร้อม URL HTTPS ในโดเมน Shopee ที่กำหนด (การตรวจรูปแบบลิงก์ไม่รับรองการติดตามค่าคอมมิชชันหรือสต็อกสด)
เลือกสินค้าที่ไม่เคยทำคลิป/เก่าสุดก่อน แล้วเรียงตามราคา × คอมมิชชัน % เพื่อไม่ทำซ้ำติดกัน; 70% Affiliate / 30% ตลกทั่วไป เมื่อ catalog ว่างจะทำคลิปตลกแทน
ตัวเลขราคาและคอมมิชชันมาจากที่เจ้าของบันทึกเอง ต้องตรวจรายงาน Shopee จริงเป็นระยะ

## งบ
คงเพดานเดือน $5 และเพิ่มเพดานวัน $0.50 ตามค่าตั้งต้น; ประมาณ $0.42 ต่อคลิปเมื่อสร้าง 3 ภาพ + TTS + Gemini ตามสมมติฐาน ไม่ใช่ราคาบิลจริง
เมื่อเกินเพดานประมาณการระบบจะหยุด; ไม่ใช่วงเงินตัดค่าใช้จ่ายจริงของผู้ให้บริการ และการหยุดงานก่อน commit state อาจทำให้ยอดบันทึกไม่ครบ
หากมี GitHub Variables MONTHLY_SPEND_CAP_USD / DAILY_SPEND_CAP_USD จะใช้ค่าที่ต่ำกว่า; image/voice estimates ใช้ค่าที่สูงกว่า; IMAGES_PER_REEL เดิมจะมีลำดับเหนือไฟล์
หากต้องการใช้ค่าใน Admin ทั้งหมดให้ตรวจหรือลบ variables เดิมที่ซ้ำซ้อนอย่างระมัดระวัง
งบไม่พอ 30 คลิป จะหยุดแทนการเพิ่มเงินเอง
